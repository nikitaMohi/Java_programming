# Java Exception Handling

## About

This repository contains Java programs demonstrating exception handling concepts through practical examples.

## Topics Covered

* Exception handling in Java
* Try and catch blocks
* Handling runtime exceptions
* Practical Java coding examples

## Programs

* `ExceptionDemo1X.java`
* `ExceptionDemo1XX.java`
* `ExceptionDemo2X.java`
* `ExceptionDemo3.java`

## Technologies Used

* Java
* JDK
* Git and GitHub

## How to Run

Compile a Java file:

```bash
javac ExceptionDemo1X.java
```

Run the program:

```bash
java ExceptionDemo1X
```

Replace the filename with the program you want to execute.
