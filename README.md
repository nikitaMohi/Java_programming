# Java Programming Concepts

A structured collection of Java programs and notes created while learning Java, progressing from core fundamentals to object-oriented programming and advanced concepts. Each topic is supported by hands-on code examples, making this repository both a learning record and a quick revision reference.

---

## About This Repository

This repository documents my Java learning journey. Programs are added regularly as each new concept is learned and practiced. It contains:

- Clean, well-commented example programs for each topic
- A progressive structure, moving from basic to advanced concepts
- Practice problems that reinforce each concept
- Continuous updates as new topics are completed

## Objectives

- Build a strong foundation in Java programming
- Strengthen problem-solving skills through consistent practice
- Maintain an organized reference for future revision
- Demonstrate learning progress and coding ability

## Topics Covered

### 1. Java Basics
- Introduction to Java, JDK, JRE, and JVM
- Structure of a Java program
- Variables and data types
- Operators and type casting
- Input and output using `Scanner` and `System.out`

### 2. Control Flow
- `if`, `if-else`, `else-if` ladder, and nested `if`
- `switch` statement
- Loops: `for`, `while`, `do-while`
- `break` and `continue`
- Pattern printing programs

### 3. Arrays and Strings
- One-dimensional and multi-dimensional arrays
- Array operations: searching, sorting, and traversal
- `String`, `StringBuilder`, and `StringBuffer`
- Common string methods and manipulation programs

### 4. Methods
- Defining and calling methods
- Parameters and return types
- Method overloading
- Recursion

### 5. Object-Oriented Programming
- Classes and objects
- Constructors
- `this` and `static` keywords
- Encapsulation
- Inheritance
- Polymorphism (compile-time and runtime)
- Abstraction using abstract classes and interfaces
- `super` and `final` keywords
- Access modifiers
- Packages

### 6. Exception Handling
- `try`, `catch`, and `finally`
- `throw` and `throws`
- Checked and unchecked exceptions
- Custom exceptions

### 7. Collections Framework
- `List`: `ArrayList`, `LinkedList`
- `Set`: `HashSet`, `TreeSet`
- `Map`: `HashMap`, `TreeMap`
- Iterators
- Sorting with `Comparable` and `Comparator`

### 8. Additional Concepts
- Wrapper classes and autoboxing
- Generics
- File handling
- Multithreading and concurrency
- Java 8 features: Lambda expressions, Streams, and Functional interfaces
- JDBC: database connectivity and CRUD operations

Additional topics will be added as I continue learning.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/nikitaMohi/<name>.git
   ```

2. Navigate to the project directory:
   ```bash
   cd <name>
   ```

3. Compile a Java file:
   ```bash
   javac FileName.java
   ```

4. Run the program:
   ```bash
   java FileName
   ```

Ensure Java is installed by running `java -version`.
